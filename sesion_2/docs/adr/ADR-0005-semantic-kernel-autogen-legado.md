# ADR-0005 · Tratar Semantic Kernel y AutoGen como tecnologías en mantenimiento

- **Estado:** aceptada
- **Fecha:** 2026-10-13

## Contexto

Microsoft Agent Framework 1.0 alcanzó disponibilidad general el 3 de abril de 2026 para .NET y Python como sucesor de Semantic Kernel y AutoGen, que pasan a modo mantenimiento (correcciones y seguridad, sin nuevas funciones).

## Decisión

Los laboratorios AZ-C y AZ-D se presentan como **legado y ruta de migración**. Los desarrollos nuevos del curso en Azure usan Microsoft Agent Framework.

## Consecuencias

Los estudiantes conocen ambos para entender sistemas existentes, sin adoptarlos en diseños nuevos.
