# Sesión 1 · Arquitecturas Base para LLMs en la Nube

Capítulo 1 · Fundamentos de Infraestructura para LLMs · 180 minutos

**Objetivo de desempeño:** al final de la sesión, el estudiante diseña en equipo una topología base para el asistente universitario que identifique al menos ocho componentes, ubique los límites de red y de confianza, y justifique por escrito la elección entre inferencia gestionada y autogestionada con al menos tres criterios.
